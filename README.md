# deviceregister / inventory system

## Plan + Requirements
- user can create an account and login (first user admin)
- admin can add, edit and remove other users
- admin can set privileges for other users
- users can add, edit and remove items from database depending on their privileges
- users can see items based on their privileges
- users can search items by the values/types/contents of items
- users have their own pages where information about that user can be seen
- items have categories based on their values/types
- users can filter items by their categories (multiple filters allowed)


- basic clean b+w html+css site (no external libraries)
- sqlite database
- only allowed external library: flask
